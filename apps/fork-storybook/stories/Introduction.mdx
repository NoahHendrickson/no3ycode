# no3y code — Basic

The fork's component library. Every story renders the app's real components from `apps/web/src`,
through the same override tree, stylesheets and theme startup as the app, so what you see here is
what ships.

- **Foundations** — colours, type, radius, spacing, elevation and icons, read live from the CSS.
- **Components** — the `components/ui` primitives (shadcn on Base UI), one page each.
- **Fork** — the fork's own components: thread cards, the composer, pickers and pills.
- **Blocks** — those pieces composed the way the app composes them.

Use the **Theme** menu in the toolbar to switch between Basic's two tones (Light and Darker Neutral), Glass and Inlet's colours.
It moves the theme the way Settings › Appearance does, so the page carries exactly the attributes the
app would. Glass is a see-through window in the desktop app; here a stand-in wallpaper shows through
it, so its blur and tints are close to the app but not exact.

The Figma kit mirrors this library page for page; its components are captured from these stories.

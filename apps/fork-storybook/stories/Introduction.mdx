# no3y code components

The components no3y code ships, in **Inlet · Jungle Art**. Nothing here is a copy: every story
renders the real component from `apps/web`, through the same override tree, stylesheets and theme
startup as the app, so what you see is what the app paints.

- **Foundations**: the Jungle Art tokens and Inlet's geometry, read from the CSS itself.
- **Components**: one page per component, with its examples, code and props.
- **Patterns**: components assembled the way the app uses them.

## Surfaces

Inlet inks a component by where it sits, so each story sits on the surface it lives on in the app.

| Surface | Where in the app                     | Marker                                                |
| ------- | ------------------------------------ | ----------------------------------------------------- |
| Frame   | The sidebar and thread tabs (cream)  | `data-sidebar-version="v2"` + `data-app-sidebar`      |
| Page    | Settings, Usage, Automations (cream) | `data-app-modal`                                      |
| Panel   | The chat column (the art)            | `data-chat-column-maximized-away`                     |
| Tabs    | The collapsed sidebar's tab strip    | `data-fork-thread-tabs` over `data-fork-thread-panes` |

## Connected popups

Everything that opens from something stays attached to it (H3 in
`.fork/notes/INLET-STYLE-RULES.md`). Two markers make the connection:

| Opens from                     | Trigger                                 | Popup                 |
| ------------------------------ | --------------------------------------- | --------------------- |
| An icon button (Dropdown menu) | `data-fork-tab-trigger`                 | `data-fork-tab-menu`  |
| A composer chip (Chip, Select) | inside `data-fork-composer-context-row` | `data-fork-chip-menu` |
